ManiMart – Project Description

ManiMart is a simple and beginner-friendly e-commerce application developed using C++. The project is created to demonstrate how an online shopping system can manage users and their accounts through a simple console-based interface.

The main purpose of ManiMart is to provide basic user registration and login functionality. New users can create an account by entering a username and password. The system checks whether the username already exists and also validates the length of the username and password.

After registration, users can log in using their registered username and password. If the entered details are correct, the user is successfully logged in and can access their account. The user can also view their profile and logout from the account.

ManiMart uses file handling in C++ to store user information in a file called "users.txt". This means the registered user details can be available even after the program is closed and started again.

The project also demonstrates important Object-Oriented Programming concepts such as classes, objects, constructors, private data members, and member functions. The "User" class is used to store and manage the username and password of each user.

Main Features

1. User Registration – New users can create a ManiMart account.
2. Login System – Registered users can log in using their credentials.
3. Username Validation – The system checks that the username has at least 3 characters.
4. Password Validation – The system checks that the password has at least 6 characters.
5. Duplicate Checking – The system prevents users from registering with an existing username.
6. Profile View – Logged-in users can view their username and account status.
7. Logout – Users can safely logout from their account.
8. File Storage – User information is stored in "users.txt".
9. Default Account – The program provides an initial admin account for testing.

Technologies Used

- Programming Language: C++
- File: "users.txt"
- Concepts: Object-Oriented Programming, File Handling, Functions, Loops and Conditions
- Interface: Console-based application

Conclusion

ManiMart is a simple project that helps demonstrate how basic C++ programming concepts can be used to create an e-commerce account system. It provides essential features such as registration, login, profile viewing, and logout. The project can be further developed by adding products, shopping cart, orders, payment options, and other e-commerce features.
